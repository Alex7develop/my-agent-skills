# Definition of done

Standing bar for changes in projects that use this skill pack. Per-task acceptance criteria from `spec-first` still apply on top.

- [ ] Behavior matches the agreed spec / acceptance checks
- [ ] Tests cover the changed behavior (or a bug-repro test for fixes)
- [ ] No unrelated refactors mixed into the same change
- [ ] `code-review` axes checked (correctness, readability, security, performance, tests)
- [ ] Commit / PR explains **why**, not only what
- [ ] Risks and out-of-scope items called out honestly
